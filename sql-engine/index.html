How SQL Server reads and writes pages

SQL Server Storage Engine

Four interactive pages about B+ tree indexes on disk: what's inside an 8 KB page, how a seek with key lookups walks two trees, a game where you execute statements by hand, and a platformer where every room is an index page.

1Inside an 8 KB PageA to-scale byte map of a clustered and a nonclustered leaf page. Insert and delete rows to see compaction and page splits. 2Key Lookup WalkthroughStep through an Index Seek plus Key Lookup one page read at a time, then find where the plan flips to a scan. 3Storage Engine DrillTwelve levels: seeks, INCLUDE, ranges, ORDER BY and TOP, writes, heaps, statistics, plan reuse, index design, joins, locks, and blocking and isolation. Plus Peak Load, an arcade mode where you keep a server alive through waves of live traffic. 4Page RunnerA platformer where every room is a B+ tree page. Drop through separator trapdoors, walk the leaf chain, run key lookups and split a full page and get out of a deadlock, scored in logical reads.
