SQL Server Storage Engine

Three interactive pages about B+ tree indexes on disk: what's inside an 8 KB page, how a seek with key lookups walks two trees, and a game where you execute statements by hand.

1Inside an 8 KB PageA to-scale byte map of a clustered and a nonclustered leaf page. Insert and delete rows to see compaction and page splits. 2Key Lookup WalkthroughStep through an Index Seek plus Key Lookup one page read at a time, then find where the plan flips to a scan. 3Storage Engine DrillTen levels: seeks, INCLUDE, ranges, ORDER BY and TOP, writes, heaps, statistics, plan reuse, index design and joins. Plus Peak Load, an arcade mode where you keep a server alive through waves of live traffic.
